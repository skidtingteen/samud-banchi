# สมุดบัญชี — คู่มือการใช้งานฉบับละเอียด

โปรแกรมบัญชีสำหรับฟรีแลนซ์และกิจการขนาดเล็กในไทย ทั้งโปรแกรมอยู่ในไฟล์ HTML ไฟล์เดียว เปิดใช้ได้ทั้งใน Claude ในเบราว์เซอร์บนคอมพิวเตอร์ หรือทำเป็นเว็บให้คนอื่นเปิดจากมือถือ

- บันทึกรายรับ-รายจ่าย พร้อม VAT 7% และหักภาษี ณ ที่จ่าย
- ออกเอกสาร 10 ประเภท ส่งออกเป็น PDF, JPEG หรือสั่งพิมพ์
- แนบหลักฐานตัวจริง (PDF / JPEG / PNG) ได้หลายไฟล์ต่อรายการ
- สแกนใบเสร็จได้ 2 แบบ: ด้วย AI หรืออ่านในเครื่องแบบออฟไลน์
- สรุปภาษีรายเดือน ปฏิทินยื่นแบบ งบกำไรขาดทุน และลูกหนี้/เจ้าหนี้
- ข้อมูลของแต่ละคนอยู่ในเครื่องของคนนั้น ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ใด ๆ

> ข้อมูลภาษีในคู่มือนี้เป็นข้อมูล ณ เดือนกันยายน 2569 กฎหมายและอัตราภาษีเปลี่ยนได้ ควรตรวจสอบกับกรมสรรพากรหรือผู้ทำบัญชีก่อนยื่นแบบจริง โปรแกรมนี้เป็นเครื่องมือช่วยจัดการ ไม่ใช่คำแนะนำทางภาษีหรือกฎหมาย

## 2. เริ่มใช้งานใน 10 นาที

### ขั้นที่ 1: เปิดโปรแกรม

- **คอมพิวเตอร์:** ดับเบิลคลิก `samud-banchi.html` ถ้าเปิดด้วยโปรแกรมอื่น ให้คลิกขวา > Open with > Google Chrome หรือ Microsoft Edge
- **มือถือ:** การเปิดไฟล์ HTML บนมือถือยุ่งยาก ให้ทำเป็นเว็บตามหัวข้อ 12.2 แล้วเปิดจากลิงก์แทน
- **ใน Claude:** เปิดไฟล์จากแชตได้เลย ข้อมูลบันทึกอัตโนมัติในพื้นที่ของ Claude

เบราว์เซอร์ที่แนะนำ: Chrome, Edge, Firefox หรือ Safari 16.4 ขึ้นไป

### ขั้นที่ 2: ลองด้วยข้อมูลตัวอย่าง (ไม่บังคับ)

ที่หน้าภาพรวม กด **ใส่ข้อมูลตัวอย่าง** แล้วลองกดดูทุกหน้า เมื่อพร้อมใช้จริง ไปที่ **ตั้งค่า > ล้างข้อมูลทั้งหมด**

### ขั้นที่ 3: ตั้งค่ากิจการ

ไปที่ **ตั้งค่า** แล้วกรอก:

1. **รูปแบบกิจการ:** บุคคลธรรมดา/ฟรีแลนซ์ หรือนิติบุคคล (มีผลกับปฏิทินภาษีประจำปี)
2. **ชื่อกิจการ** ตามทะเบียน และ **ที่อยู่**
3. **เลขประจำตัวผู้เสียภาษี 13 หลัก** โปรแกรมตรวจหลักสุดท้ายให้ ถ้ากรอกผิดช่องจะเป็นสีแดง
4. **สำนักงานใหญ่ / สาขา** เช่น `สำนักงานใหญ่` หรือ `สาขาที่ 00001` (ใบกำกับภาษีต้องมี)
5. **จดทะเบียน VAT แล้ว** ติ๊กเฉพาะเมื่อจดแล้วจริง
6. **ชื่อผู้มีอำนาจลงนาม** และตำแหน่ง
7. **โลโก้** และ **ลายเซ็น** (ใช้รูปพื้นหลังโปร่งใสจะสวยที่สุด)
8. **พร้อมเพย์** (เบอร์มือถือหรือเลข 13 หลัก) และ **บัญชีรับโอน** จะไปแสดงบนใบแจ้งหนี้

### ขั้นที่ 4: ปรับหมวดหมู่

ใน **ตั้งค่า > หมวดหมู่และงบประมาณ** เพิ่ม ลบ หรือแก้ชื่อหมวดได้ แต่ละหมวดรายจ่ายตั้งได้ว่า:

- **งบต่อเดือน:** หน้าภาพรวมจะแสดงแถบเทียบงบ
- **หัก ณ ที่จ่ายเริ่มต้น:** เช่น ค่าเช่า 5% ระบบเติมอัตราให้เองเมื่อเลือกหมวดนี้
- **ภาษีซื้อต้องห้าม:** VAT ของหมวดนี้จะรวมเป็นค่าใช้จ่าย ไม่นำไปหักภาษีขาย (เช่น ค่ารับรอง รถยนต์นั่ง)

### ขั้นที่ 5: บันทึกรายการแรก

ไปที่ **รายรับ-รายจ่าย > + รายจ่าย** กรอกข้อมูล แนบรูปใบเสร็จ แล้วกดบันทึก

### ขั้นที่ 6: ดาวน์โหลดไฟล์สำรองครั้งแรก

**ตั้งค่า > ดาวน์โหลดไฟล์สำรอง (.json)** แล้วเก็บไว้ใน Google Drive หรือที่อื่นที่ปลอดภัย (อ่านเหตุผลในหัวข้อ 3)

## 3. ข้อมูลเก็บที่ไหน และการสำรองข้อมูล (สำคัญ)

### ที่เก็บข้อมูลแต่ละแบบ

มุมซ้ายล่างของโปรแกรม (หรือเมนูเพิ่มเติมบนมือถือ) จะบอกว่าตอนนี้บันทึกไว้ที่ไหน

| วิธีเปิด | ข้อมูลเก็บที่ | สิ่งที่ต้องรู้ |
|---|---|---|
| เปิดใน Claude | พื้นที่เก็บข้อมูลของ Claude ผูกกับไฟล์นั้น | บันทึกอัตโนมัติ |
| เปิดไฟล์ในเบราว์เซอร์ หรือเปิดจากลิงก์เว็บ | ในเบราว์เซอร์ของเครื่องนั้น | บันทึกอัตโนมัติ แต่ **ถ้าล้างข้อมูลเบราว์เซอร์ ถอนการติดตั้งเบราว์เซอร์ หรือเครื่องเสีย ข้อมูลหาย** |
| กด "เปิด/สร้างไฟล์ข้อมูล" (Chrome/Edge บนคอม) | ไฟล์ `.json` ที่คุณเลือก | บันทึกลงไฟล์ทุกครั้งที่แก้ วางไฟล์ในโฟลเดอร์ที่ซิงก์ Google Drive ได้ ต้องกดเปิดไฟล์ใหม่ทุกครั้งที่เข้าโปรแกรม |
| โหมดชั่วคราว (เบราว์เซอร์ไม่อนุญาตให้เก็บข้อมูล) | หน่วยความจำเท่านั้น | **ข้อมูลหายเมื่อปิดหน้า** ต้องดาวน์โหลดสำรองก่อนปิด |

ข้อควรรู้:

- ข้อมูล **ไม่ซิงก์ข้ามเครื่อง** ถ้าใช้ทั้งคอมและมือถือ ข้อมูลจะแยกกันคนละชุด
- ข้อมูลใน Claude กับข้อมูลในเบราว์เซอร์ก็เป็นคนละชุด ย้ายด้วยไฟล์สำรอง

### วิธีสำรองข้อมูล

**ตั้งค่า > ข้อมูลและการสำรอง > ดาวน์โหลดไฟล์สำรอง (.json)**

- ไฟล์สำรองมีทุกอย่าง: รายการ เอกสาร ผู้ติดต่อ การตั้งค่า และไฟล์แนบทั้งหมด
- ถ้ามีไฟล์แนบเยอะ ไฟล์สำรองจะใหญ่ตาม
- API key ของ AI **ไม่ถูกรวม** ในไฟล์สำรอง
- ถ้าเก็บในเบราว์เซอร์และไม่ได้สำรองเกิน 30 วัน โปรแกรมจะขึ้นเตือนที่หน้าภาพรวม

ควรสำรองเมื่อ:

- อย่างน้อยเดือนละครั้ง หรือหลังปิดยอดแต่ละเดือน
- ก่อนล้างเครื่อง เปลี่ยนเครื่อง อัปเดตระบบใหญ่ หรือล้างข้อมูลเบราว์เซอร์

### วิธีกู้คืน / ย้ายเครื่อง

1. เปิดโปรแกรมบนเครื่องใหม่
2. **ตั้งค่า > กู้คืนจากไฟล์สำรอง** แล้วเลือกไฟล์ `.json`
3. ยืนยัน โดยข้อมูลเดิมในเครื่องนั้นจะถูกแทนที่ทั้งหมด

### กฎหมายเรื่องการเก็บเอกสาร

- เก็บเอกสารประกอบการลงบัญชีและเอกสารภาษีไว้อย่างน้อย 5 ปี
- ไฟล์แนบในโปรแกรมเป็นสำเนาเพื่อความสะดวก **ควรเก็บใบกำกับภาษีและเอกสารกระดาษฉบับจริงไว้ด้วย** เพราะการใช้สิทธิ์ภาษีซื้อและการตรวจสอบของสรรพากรมักต้องดูต้นฉบับ (ยกเว้นเอกสารที่ออกเป็น e-Tax Invoice)

## 4. หน้าภาพรวม

- **ตัวเลือกช่วงเวลา:** รายเดือน รายไตรมาส รายปี ทั้งหมด หรือกำหนดเอง ใช้ร่วมกับหน้ารายรับ-รายจ่าย
- **งบกำไรขาดทุนย่อ:** รายได้ (ไม่รวม VAT) ลบค่าใช้จ่าย แยกตามหมวด พร้อมอัตรากำไร เงินรับจริง และภาษีที่ถูกหัก ณ ที่จ่าย กด PDF/JPEG เพื่อส่งออกหน้าสรุป
- **ภาษีของช่วงนี้:** ภาษีขาย ภาษีซื้อ VAT ที่ต้องชำระ หัก ณ ที่จ่ายที่ต้องนำส่ง และวันครบกำหนดยื่น
- **ลูกหนี้และเจ้าหนี้:** ยอดค้างรับ ยอดเกินกำหนด ยอดค้างจ่าย
- **แฟ้มงานที่กำลังทำ:** จำนวนงานที่เปิดอยู่ ค้างรับรวม และงานที่ค้างรับมากที่สุด
- **เงินคงเหลือตามบัญชี:** คำนวณจากยอดยกมาและรายการที่ชำระแล้ว
- **กราฟ 12 เดือน:** แท่งเขียวคือรายรับ แท่งแดงคือรายจ่าย เส้นคือกำไร
- **แถบแจ้งเตือนด้านบน:**
  - รายการประจำถึงกำหนด
  - ลูกหนี้เกินกำหนด และบิลที่ใกล้ครบกำหนด
  - 50 ทวิ ที่ยังไม่ได้รับจากลูกค้า หรือยังไม่ได้ออกให้ผู้รับเงิน
  - รายได้ใกล้เกณฑ์จด VAT
  - ถึงเวลาสำรองข้อมูล

## 5. รายรับ-รายจ่าย

### เพิ่มรายการ

กด **+ รายรับ** หรือ **+ รายจ่าย** แล้วกรอกตามนี้

| ช่อง | คำอธิบาย |
|---|---|
| ชำระแล้ว / ยังไม่ได้รับ-จ่าย | ถ้ายังไม่ชำระ ใส่วันครบกำหนด รายการจะไปอยู่ในลูกหนี้/เจ้าหนี้ |
| วันที่ในเอกสาร | วันที่บนใบเสร็จหรือใบกำกับภาษี |
| หมวดหมู่ | มีผลกับงบกำไรขาดทุน อัตราหัก ณ ที่จ่ายเริ่มต้น และภาษีซื้อต้องห้าม |
| คู่ค้า | พิมพ์ชื่อผู้ติดต่อที่บันทึกไว้ ระบบเติมเลขผู้เสียภาษีและแบบ ภ.ง.ด. ให้ |
| จำนวนเงิน + รูปแบบ VAT | **ไม่มี VAT**, **ยังไม่รวม VAT** (ระบบบวก 7%) หรือ **รวม VAT แล้ว** (ระบบถอด VAT ออกจากยอด) |
| ยอด VAT ตามเอกสาร | ถ้า VAT บนใบเสร็จต่างจากที่คำนวณเพราะการปัดเศษ ให้ใส่ตัวเลขตามเอกสาร |
| หักภาษี ณ ที่จ่าย | เลือกอัตรา (ดูตารางในหัวข้อ 14) คิดจากยอดก่อน VAT |
| ยื่นในแบบ | ภ.ง.ด.3 เมื่อจ่ายบุคคลธรรมดา หรือ ภ.ง.ด.53 เมื่อจ่ายนิติบุคคล |
| เอกสารภาษีที่ได้รับ | ใบกำกับเต็มรูป ใบกำกับอย่างย่อ หรือไม่มี (มีผลกับการใช้สิทธิ์ภาษีซื้อ) |
| เดือนภาษีที่ใช้สิทธิ์ | ถ้าจะเลื่อนไปใช้ภาษีซื้อในเดือนหลัง ใช้ได้ไม่เกิน 6 เดือนถัดจากเดือนที่ออกใบกำกับ |
| ออก/ได้รับ 50 ทวิ แล้ว | ติ๊กเพื่อติดตามหนังสือรับรองการหักภาษี |
| ค่าบริการจากต่างประเทศ | เช่น ค่าโฆษณา Facebook/Google ที่ไม่ได้เก็บ VAT ไทย ระบบคำนวณ VAT ที่ต้องนำส่งตาม ภ.พ.36 |
| หลักฐาน / ไฟล์แนบ | ดูหัวข้อ 6 |
| ทำซ้ำทุกเดือน | สร้างรายการประจำ เช่น ค่าเช่า ค่าอินเทอร์เน็ต |
| รายการสินค้า / บริการ | ซื้ออะไรบ้าง กี่ชิ้น ชิ้นละเท่าไร (หัวข้อ 5.1) |
| แฟ้มงาน | ผูกรายการกับงาน (หัวข้อ 9) หรือเลือกสร้างแฟ้มงานใหม่เมื่อบันทึก |

ช่องสรุปด้านล่างของฟอร์มแสดงมูลค่าก่อน VAT, VAT, ยอดรวม, หัก ณ ที่จ่าย และยอดรับ/จ่ายจริงแบบทันที

### 5.1 รายการสินค้าในบิลเดียว

ใบเสร็จหนึ่งใบมักมีหลายรายการ กดหัวข้อ **รายการสินค้า / บริการ** ในฟอร์มเพื่อใส่ทีละบรรทัด

- ช่องคือ ชื่อสินค้า, จำนวน, หน่วย, ราคาต่อหน่วย และจำนวนเงิน
- กรอกช่องไหนก็ได้ ระบบคิดที่เหลือให้: ใส่จำนวนกับราคาต่อหน่วยแล้วได้จำนวนเงิน หรือใส่จำนวนกับจำนวนเงินแล้วได้ราคาต่อหน่วย
- ใต้ตารางจะบอกว่าผลรวมรายการตรงกับยอดในเอกสารหรือไม่ ถ้าไม่ตรงจะขึ้นส่วนต่างที่แน่นอนถึงสตางค์ให้ตรวจ (ไม่บังคับให้ตรง เพราะบางใบมีส่วนลดท้ายบิลหรือค่าบริการ)
- รายการเป็นตัวเลือกเสริม ไม่ใส่ก็บันทึกได้ตามปกติ VAT และหัก ณ ที่จ่ายยังคิดจากยอดรวมด้านบนเหมือนเดิม

**ประโยชน์**
- ในหน้ารายรับ-รายจ่าย รายการที่มีสินค้าจะมีปุ่มบอกจำนวนรายการ กดดูได้ว่าซื้ออะไรไปบ้าง
- ค้นหาด้วยชื่อสินค้าได้ เช่น พิมพ์ "หมึกพิมพ์" เพื่อดูว่าเคยซื้อเมื่อไร ราคาเท่าไร
- ส่งออก **รายการสินค้า CSV** เพื่อดูรายบรรทัดใน Excel
- ดูสรุปที่ **รายงาน > สินค้าที่ซื้อ** (หัวข้อ 11)
- เมื่อออกเอกสารจากรายการนี้ เช่น ใบรับรองแทนใบเสร็จ ระบบใส่รายการสินค้าให้ในเอกสารเลย

### สิ่งที่ระบบคิดให้อัตโนมัติ

- **รายได้** ในงบกำไรขาดทุนไม่รวม VAT
- **VAT ที่ใช้สิทธิ์ไม่ได้** จะนับรวมเป็นค่าใช้จ่าย ได้แก่:
  - ใบกำกับอย่างย่อ
  - ไม่มีใบกำกับภาษี
  - หมวดที่ตั้งเป็นภาษีซื้อต้องห้าม
  - กิจการที่ยังไม่ได้จด VAT
- **เตือนรายการซ้ำ** เมื่อพบรายการวันเดียวกัน ยอดเท่ากัน คู่ค้าหรือเลขที่เอกสารเดียวกัน

### เมนูของแต่ละรายการ (ปุ่ม ⋯)

แก้ไข, ทำสำเนา, ทำเครื่องหมายว่าชำระแล้ว, ออก 50 ทวิ, ออกใบรับรองแทนใบเสร็จ, ออกใบสำคัญรับเงิน, เปิดเอกสารต้นทาง, ลบ

### ตัวกรอง "ตรวจสอบ"

ใช้หารายการที่ต้องจัดการ:

- ไม่มีหลักฐานแนบ
- มี VAT
- มีหัก ณ ที่จ่าย
- ยังไม่มี 50 ทวิ
- ค่าบริการต่างประเทศ
- รายการประจำ
- ไม่อยู่ในแฟ้มงาน

### ส่งออก CSV

ปุ่ม **CSV** จะส่งออกรายการตามตัวกรองที่เลือกอยู่ เปิดด้วย Excel หรือ Google Sheets ได้โดยภาษาไทยไม่เพี้ยน

## 6. ไฟล์แนบและหลักฐาน

แนบไฟล์ตัวจริงได้หลายไฟล์ ทั้ง **PDF, JPEG และ PNG** ใน 4 ที่

| แนบที่ | ตัวอย่างที่ควรแนบ |
|---|---|
| รายการรับ-จ่าย | ใบเสร็จ/ใบกำกับภาษีตัวจริง สลิปโอนเงิน |
| เอกสาร (ทุกประเภท) | สลิปโอนของลูกค้า ใบสั่งซื้อ ใบเสนอราคาที่ลูกค้าเซ็น ใบส่งของ รูปงานที่ส่งมอบ สำเนาบัตรของผู้รับเงิน (ใบสำคัญรับเงิน) 50 ทวิ ที่เซ็นแล้ว |
| ผู้ติดต่อ | หนังสือรับรองบริษัท ภ.พ.20 สำเนาบัตรประชาชน |
| แฟ้มงาน | สัญญา บรีฟงาน รูปงานที่ส่งมอบ |

### วิธีแนบ

1. ในฟอร์ม กด **แนบไฟล์ PDF / JPEG / PNG** แล้วเลือกได้หลายไฟล์พร้อมกัน
2. เลือกประเภทของแต่ละไฟล์ เช่น "สลิปโอนเงิน / หลักฐานการชำระ"
3. กดรูปย่อเพื่อเปิดดู หรือกด × เพื่อเอาออก
4. **กดบันทึกฟอร์ม** ไฟล์จะถูกเก็บจริงตอนนี้ ถ้ากดยกเลิก ไฟล์ที่เพิ่งแนบจะไม่ถูกเก็บ

ขนาดและคุณภาพไฟล์:

- **PDF:** เก็บต้นฉบับทุกไบต์ ขนาดสูงสุด 15 MB ต่อไฟล์
- **รูป JPEG/PNG ไม่เกิน 6 MB:** เก็บต้นฉบับ
- **รูปใหญ่กว่า 6 MB หรือไฟล์แบบอื่น (เช่น WebP):** ย่อด้านยาวเหลือ 3200 px ยังอ่านตัวหนังสือได้ชัด
- **HEIC จาก iPhone:** ถ้าเลือกจากแอปรูปภาพบน iPhone ระบบจะแปลงเป็น JPEG ให้เอง แต่ถ้าเป็นไฟล์ HEIC บนคอมพิวเตอร์ ให้แปลงเป็น JPEG ก่อน

การดูไฟล์แนบภายหลัง:

- ในรายการที่มีไฟล์แนบ จะมีไอคอนคลิปพร้อมจำนวนไฟล์ กดเพื่อเปิดดูหรือดาวน์โหลด
- รายการรับ-จ่ายที่สร้างจากเอกสาร จะแสดงไฟล์แนบของเอกสารนั้นด้วย

### ส่งเอกสารให้ลูกค้าพร้อมหลักฐานในไฟล์เดียว

1. เปิดเอกสาร แนบไฟล์ แล้วกด **บันทึก**
2. กด **PDF**
3. ติ๊ก **รวมไฟล์แนบ n ไฟล์ไว้ท้าย PDF**
4. กดสร้างไฟล์

ผลลัพธ์คือ PDF ที่มีตัวเอกสารก่อน ตามด้วยทุกหน้าของ PDF ที่แนบ และรูปภาพแต่ละรูป (1 รูปต่อ 1 หน้า A4 วางแนวตั้งหรือแนวนอนตามรูป) PDF ที่มีรหัสผ่านอาจรวมไม่ได้ ระบบจะแจ้งชื่อไฟล์ที่ข้าม

### สแกนใบเสร็จแล้วได้หลักฐานเลย

เมื่อบันทึกจากหน้าสแกน โปรแกรมเก็บไฟล์ต้นฉบับที่ถ่ายหรืออัปโหลดไว้เป็นไฟล์แนบของรายการให้อัตโนมัติ

## 7. สแกนใบเสร็จ

### ขั้นตอน

1. ไปที่ **สแกนใบเสร็จ**
2. เลือก **บันทึกเป็น** รายจ่ายหรือรายรับ
3. เลือก **วิธีอ่าน**:

| วิธีอ่าน | เหมาะกับ | ต้องมี |
|---|---|---|
| อัตโนมัติ | ใช้ทั่วไป | ใช้ AI ถ้ามี ถ้าไม่มีหรือเชื่อมต่อไม่ได้จะอ่านในเครื่องแทน |
| AI (Claude) | แม่นที่สุด อ่านได้ทั้งรูปและ PDF | เปิดใน Claude หรือใส่ API key ของตัวเอง (หัวข้อ 13) |
| ในเครื่อง (ออฟไลน์) | ไม่มีเน็ต หรือไม่อยากส่งรูปออกไปไหน | เบราว์เซอร์รุ่นใหม่ (รองรับเฉพาะรูป ไม่รองรับ PDF) |

4. กด **ถ่ายรูป** (มือถือ) หรือ **เลือกไฟล์** (เลือกได้หลายไฟล์) หรือลากไฟล์มาวาง
5. รอให้ขึ้น "ตรวจแล้วกดบันทึก" แล้ว **ตรวจทุกช่อง** ตามเช็กลิสต์ด้านล่าง รวมทั้งกดดู **รายการสินค้า** ที่ระบบแยกให้
6. กด **บันทึก** ทีละใบ หรือ **บันทึกทั้งหมด**

### เช็กลิสต์ก่อนบันทึก

- **ยอดรวม** และ **VAT** ตรงกับใบเสร็จ
- **วันที่** ถูกต้อง (ใบเสร็จไทยมักเป็นปี พ.ศ. ระบบแปลงให้แล้ว)
- **เลขผู้เสียภาษีผู้ขาย** ตรง
- **ประเภทเอกสาร:** ใบกำกับเต็มรูปต้องมีชื่อ ที่อยู่ และเลขผู้เสียภาษีของ **กิจการเรา** ถ้าไม่มี ให้เลือกอย่างย่อหรือไม่มี
- **รายการสินค้า:** กดแถบ "รายการสินค้า" เพื่อดูว่าแยกได้กี่บรรทัด แก้ชื่อ จำนวน หรือราคาได้ทันที ถ้าผลรวมไม่ตรงกับยอดบิลจะมีข้อความเตือนไว้ใต้ตาราง
- **หมวดหมู่** ถูกต้อง
- ถ้าจ่ายค่าบริการที่ต้องหัก ณ ที่จ่าย ให้เลือกอัตรา

ป้ายเตือนที่อาจเห็น:

- "อาจซ้ำกับรายการ…"
- "ใบกำกับอย่างย่อ ใช้เป็นภาษีซื้อไม่ได้"
- "ใบกำกับภาษีไม่ได้ออกในนามกิจการ"
- "อ่านตัวเลขได้ไม่ชัด"

### เคล็ดลับให้อ่านแม่นขึ้น

- วางใบเสร็จบนพื้นเรียบสีเข้ม ถ่ายตรงจากด้านบนให้เต็มกรอบ
- แสงพอ ไม่มีเงามือทับตัวเลข ไม่มีแสงสะท้อน
- ใบเสร็จยาวให้ถ่ายใกล้ขึ้น หรือถ่ายเป็น 2 รูป
- ถ้ารูปตะแคง กด **หมุนภาพ** ระบบจะอ่านใหม่
- ใบเสร็จกระดาษความร้อนที่ซีดมาก ถ่ายให้คมที่สุดแล้วตรวจตัวเลขเอง
- โหมดในเครื่องจะมีช่อง **ข้อความที่อ่านได้จากภาพ** ใช้เทียบเมื่อตัวเลขผิด

### ความแม่นยำโดยประมาณ

- **AI:** แม่นที่สุด แยกรายการสินค้าได้ดีที่สุด รวมถึงใบเสร็จที่มีหลายบรรทัดหรือจัดหน้าซับซ้อน
- **ในเครื่อง:** แยกรายการสินค้าได้เมื่อใบเสร็จพิมพ์เป็นบรรทัดชัดเจนและผลรวมของรายการตรงกับยอดบิล ถ้าไม่ตรงระบบจะไม่เดา แต่ปล่อยให้ใส่เอง ส่วนใบเสร็จพิมพ์ชัดจะได้ยอดรวม VAT และเลขผู้เสียภาษีถูกเป็นส่วนใหญ่ ส่วนใบเสร็จซีด ยับ บิลเขียนมือ หรือฟอนต์แปลกจะผิดบ่อยขึ้น ครั้งแรกที่ใช้ต้องรอโหลดตัวอ่านไม่กี่วินาที

## 8. เอกสาร

### ประเภทเอกสาร

| เอกสาร | ใช้เมื่อ | หมายเหตุ |
|---|---|---|
| ใบเสนอราคา | เสนอราคาก่อนเริ่มงาน | ใส่เงื่อนไข วันยืนราคา แปลงเป็นใบแจ้งหนี้ได้ |
| ใบแจ้งหนี้ / ใบวางบิล | เรียกเก็บเงิน | แสดง QR พร้อมเพย์ตามยอดสุทธิหลังหัก ณ ที่จ่าย ติดตามวันครบกำหนด |
| ใบกำกับภาษี / ใบเสร็จรับเงิน | ได้รับชำระ (งานบริการ) หรือส่งมอบสินค้า | เฉพาะกิจการที่จด VAT บันทึกรายรับให้อัตโนมัติ มีข้อความ "เอกสารออกเป็นชุด" |
| ใบเสร็จรับเงิน | ยืนยันการรับเงิน | สำหรับกิจการที่ไม่ได้จด VAT บันทึกรายรับให้อัตโนมัติ |
| ใบลดหนี้ | ลดยอดจากใบกำกับภาษีที่ออกไปแล้ว | ต้องอ้างเลขที่ใบกำกับเดิมและเหตุผล สร้างรายรับติดลบให้ |
| ใบเพิ่มหนี้ | เพิ่มยอดจากใบกำกับภาษีที่ออกไปแล้ว | ต้องอ้างเลขที่ใบกำกับเดิมและเหตุผล |
| ใบสั่งซื้อ | สั่งซื้อจากผู้ขาย | |
| หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) | เราหักภาษีตอนจ่ายเงิน | ส่งออกได้ทั้งฉบับที่ 1 และ 2 ออกได้จากรายการรายจ่ายหรือหน้าภาษี |
| ใบรับรองแทนใบเสร็จรับเงิน | ซื้อของที่เรียกใบเสร็จไม่ได้ เช่น ตลาดสด | บันทึกรายจ่ายให้อัตโนมัติ |
| ใบสำคัญรับเงิน | จ่ายบุคคลที่ไม่มีใบเสร็จ เช่น ฟรีแลนซ์ | ให้ผู้รับเงินเซ็นและแนบสำเนาบัตร |

### ลำดับการทำงานที่แนะนำ

**งานบริการ (จด VAT):**
ใบเสนอราคา → กด **สร้างใบแจ้งหนี้** → ลูกค้าโอน → กด **รับชำระ** ได้ใบกำกับภาษี/ใบเสร็จ → แนบสลิปของลูกค้า → ส่ง PDF ให้ลูกค้า
ทุกเอกสารในลำดับนี้อยู่ในแฟ้มงานเดียวกันอัตโนมัติ ถ้าเก็บมัดจำหรือแบ่งจ่าย ดูหัวข้อ 9.3

**กิจการที่ไม่จด VAT:**
ใบเสนอราคา → ใบแจ้งหนี้ → กด **รับชำระ** ได้ใบเสร็จรับเงิน

**ต้องแก้ยอดหลังออกใบกำกับไปแล้ว:**
เปิดใบกำกับภาษี → กด **ใบลดหนี้** หรือ **ใบเพิ่มหนี้** → ใส่ส่วนต่างและเหตุผล

**จ้างฟรีแลนซ์และหัก 3%:**
บันทึกรายจ่าย (หัก 3%, ภ.ง.ด.3) → เมนู ⋯ → **ออก 50 ทวิ** และ **ออกใบสำคัญรับเงิน** → แนบสำเนาบัตร

### แก้ไขเอกสาร

- ด้านซ้ายเป็นฟอร์ม ด้านขวาเป็นตัวอย่างขนาดย่อที่อัปเดตทันที บนมือถือกดสลับ **แก้ไข / ตัวอย่าง**
- **เลขที่เอกสาร:** รูปแบบคือ คำนำหน้า + ปีเดือน + ลำดับ เช่น `QT202609-001` เริ่มลำดับใหม่ทุกเดือน แก้คำนำหน้าได้ในตั้งค่า
- **รายการสินค้า:** พิมพ์ชื่อสินค้าที่บันทึกไว้ในหน้าผู้ติดต่อ & สินค้า ระบบเติมหน่วยและราคาให้
- **ยอดเงินและภาษี:** ส่วนลดรายบรรทัด (%) ส่วนลดท้ายบิล VAT แยกหรือรวม และหัก ณ ที่จ่าย
- **ตัวเลือกเพิ่มเติม:** แสดง QR พร้อมเพย์ ใส่ลายเซ็น
- **ปุ่มลัด:** กด Ctrl+S (หรือ ⌘S) เพื่อบันทึก

### ส่งออก

- **PDF:** ขนาด A4 เลือกได้ว่าเป็นต้นฉบับ ต้นฉบับ+สำเนา สำเนา หรือไม่ระบุ แสดงตราสถานะได้ และรวมไฟล์แนบท้ายไฟล์ได้
- **JPEG:** ถ้ามีหลายหน้าจะรวมเป็นรูปเดียว เหมาะส่ง LINE
- **พิมพ์:** เลือกเครื่องพิมพ์ "บันทึกเป็น PDF" จะได้ PDF ที่ข้อความคมและค้นหาได้ (ใน Claude อาจสั่งพิมพ์ไม่ได้ ให้ใช้ PDF แทน)

### ยกเลิกหรือลบเอกสาร

- เอกสารที่ส่งให้ลูกค้าแล้วควรใช้ **⋯ > ยกเลิกเอกสาร** ไม่ควรลบ เพื่อให้เลขที่เอกสารต่อเนื่องตรวจสอบได้
- เมื่อยกเลิก รายการรับ-จ่ายที่ระบบสร้างจากเอกสารนั้นจะถูกลบให้

## 9. แฟ้มงาน

แฟ้มงานรวมทุกอย่างของงานหนึ่งงานไว้ที่เดียว ตั้งแต่ใบเสนอราคา ใบแจ้งหนี้ ใบกำกับภาษี/ใบเสร็จ ค่าใช้จ่ายของงาน ไปจนถึงไฟล์หลักฐานทั้งหมด พร้อมยอดค้างรับและกำไรของงาน

### 9.1 แฟ้มงานถูกสร้างอย่างไร

- **อัตโนมัติ:** บันทึกใบเสนอราคาใหม่ ระบบสร้างแฟ้มงานให้ (ช่อง "แฟ้มงาน" ตั้งค่าเริ่มต้นไว้ที่ "+ สร้างแฟ้มงานใหม่เมื่อบันทึก" เปลี่ยนเป็นแฟ้มเดิม หรือ "ไม่อยู่ในแฟ้มงาน" ก็ได้)
- **ตามการแปลงเอกสาร:**
  - ใบแจ้งหนี้ ใบกำกับภาษี/ใบเสร็จ และใบลด/เพิ่มหนี้ ที่สร้างจากเอกสารในแฟ้ม จะอยู่ในแฟ้มเดียวกัน
  - ถ้าเอกสารต้นทางยังไม่มีแฟ้ม ระบบสร้างแฟ้มใหม่และดึงเอกสารต้นทางเข้ามาด้วย
  - รายรับที่ระบบบันทึกจากใบกำกับภาษี/ใบเสร็จ อยู่ในแฟ้มเดียวกับเอกสาร
- **สร้างเอง:** **แฟ้มงาน > + แฟ้มงานใหม่** ติ๊ก "สร้างใบเสนอราคาของงานนี้ต่อเลย" ได้
- **ข้อมูลเดิม:** เอกสารที่เคยแปลงต่อกันไว้ก่อนมีฟีเจอร์นี้ จะถูกจัดเป็นแฟ้มงานให้อัตโนมัติครั้งแรกที่เปิดโปรแกรมเวอร์ชันนี้

### 9.2 หน้าแฟ้มงาน

| ส่วน | แสดงอะไร |
|---|---|
| สรุปงาน | มูลค่างาน (รวม VAT), รับชำระแล้ว, ค้างรับ, แถบความคืบหน้า, ยอดวางบิล, เงินเข้าจริง และภาษีที่ลูกค้าหัก ณ ที่จ่าย |
| ขั้นต่อไป | ปุ่มลัดตามสถานะงาน เช่น สร้างใบแจ้งหนี้ บันทึกรับชำระ วางบิลส่วนที่เหลือ ปิดงาน ติดตาม 50 ทวิ |
| กำไรของงาน | รายได้ (ไม่รวม VAT), ต้นทุนแยกหมวด, กำไรและอัตรากำไร, กำไรที่คาดเมื่อรับเงินครบ |
| ลำดับงาน | เอกสารและรายการรับ-จ่ายเรียงตามวันที่ กดเปิด ส่งออก PDF หรือนำออกจากแฟ้มได้ |
| ค่าใช้จ่ายของงาน | รายจ่ายที่ผูกกับงาน พร้อมไฟล์แนบ |
| ไฟล์ทั้งหมดในแฟ้ม | ไฟล์ที่แนบในทุกเอกสารและรายการของงาน รวมกับไฟล์ของแฟ้มเอง เช่น สัญญา บรีฟ รูปงานที่ส่งมอบ (ไฟล์ของแฟ้มบันทึกทันทีที่แนบ) |
| บันทึกของงาน | ข้อตกลง กำหนดส่ง ผู้ติดต่อ บันทึกอัตโนมัติขณะพิมพ์ |

**วิธีคิดยอด (คำนวณจากเอกสารและรายการทุกครั้ง ไม่ได้พิมพ์ยอดเอง และคิดถึงระดับสตางค์ ไม่ปัดเศษทิ้ง):**
- **มูลค่างาน:**
  - ใช้ใบเสนอราคาล่าสุดของแฟ้ม ถ้าไม่มีใบเสนอราคา ใช้ผลรวมใบแจ้งหนี้ ถ้าไม่มีใบแจ้งหนี้ ใช้ผลรวมใบกำกับภาษี/ใบเสร็จ
  - บวกใบเพิ่มหนี้ ลบใบลดหนี้
  - ใบเสนอราคาที่ตั้งสถานะ "ไม่อนุมัติ" หรือยกเลิก จะไม่ถูกนับ
- **รับชำระแล้ว:** รายรับในแฟ้มที่สถานะชำระแล้ว นับยอดรวม VAT และนับภาษีที่ลูกค้าหัก ณ ที่จ่ายเป็นส่วนที่ชำระแล้ว
- **ค้างรับ:** มูลค่างานลบยอดรับชำระแล้ว เหลือ 0.01 บาทก็ยังถือว่าค้าง จะได้เห็นตัวเลขจริง
- **กำไรของงาน:** รายได้ไม่รวม VAT ลบต้นทุน นับเฉพาะรายการในแฟ้ม (VAT ที่ใช้สิทธิ์ไม่ได้รวมเป็นต้นทุน)

**สถานะงาน:** งานใหม่ → เสนอราคาแล้ว → ลูกค้าอนุมัติ → วางบิลแล้ว → รับเงินบางส่วน → รับเงินครบ → ปิดงานแล้ว (หรือยกเลิก)

### 9.3 เก็บมัดจำและแบ่งจ่ายหลายงวด

กดสร้างใบแจ้งหนี้จากใบเสนอราคา หรือกดรับชำระจากใบแจ้งหนี้ จะมีหน้าต่างให้เลือกวิธีคิดยอด:

- **เต็มจำนวน:** คัดลอกทุกรายการ
- **เป็นเปอร์เซ็นต์:** เช่น มัดจำ 50%
- **ระบุจำนวนเงิน:** ใส่ยอดที่ต้องการ
- **ส่วนที่เหลือ:** ระบบคิดจากยอดที่เรียกเก็บหรือรับไปแล้ว

เอกสารแบบบางส่วนจะเป็นรายการเดียวที่อ้างอิงเอกสารต้นทาง ใช้ VAT และอัตราหัก ณ ที่จ่ายเดียวกับต้นทาง แก้ข้อความหรือยอดได้อีกครั้งก่อนบันทึก

**ตัวอย่าง: มัดจำ 50% แล้วเก็บส่วนที่เหลือเมื่อส่งงาน**
1. ใบเสนอราคา 60,000 บาท + VAT 7% = 64,200 บาท ลูกค้าอนุมัติ
2. กด **สร้างใบแจ้งหนี้** > **เป็นเปอร์เซ็นต์ 50** > ได้ใบแจ้งหนี้ 30,000 + VAT
3. ลูกค้าโอน > เปิดใบแจ้งหนี้ > **รับชำระ** > **เต็มจำนวน** > ได้ใบกำกับภาษี/ใบเสร็จ แล้วแนบสลิป
4. แฟ้มงานขึ้น "รับเงินบางส่วน" ค้างรับ 32,100 บาท และมีปุ่ม **วางบิลส่วนที่เหลือ**
5. ส่งงานแล้ว กด **วางบิลส่วนที่เหลือ** (ระบบใส่ 30,000 ให้) > ลูกค้าโอน > **บันทึกรับชำระ**
6. ค้างรับเป็น 0 สถานะเป็น "รับเงินครบ" แล้วกด **ปิดงาน**

ใบแจ้งหนี้ที่รับเงินมาบางส่วนจะมีสถานะ **ชำระบางส่วน** และหน้าลูกหนี้นับเฉพาะยอดที่ยังค้าง

### 9.4 ผูกค่าใช้จ่ายและรายการเข้ากับงาน

- **จากหน้าแฟ้มงาน:** กด **+ ค่าใช้จ่าย** หรือ **สแกนใบเสร็จ** ใบเสร็จที่สแกนจากปุ่มนี้จะเข้าแฟ้มนั้นอัตโนมัติ
- **จากฟอร์มรายรับ-รายจ่าย และการ์ดสแกน:** เลือกช่อง **แฟ้มงาน** หรือเลือก "+ สร้างแฟ้มงานใหม่เมื่อบันทึก"
- **ดึงของที่มีอยู่:** กด **เพิ่มรายการที่มีอยู่** เพื่อดึงเอกสารหรือรายการที่บันทึกไว้แล้วเข้าแฟ้ม รายการของลูกค้าเดียวกันแสดงก่อน
- **หารายการที่ยังไม่ผูก:** ใช้ตัวกรอง **ตรวจสอบ > ไม่อยู่ในแฟ้มงาน** ในหน้ารายรับ-รายจ่าย

### 9.5 ส่งออกทั้งแฟ้มเป็น PDF เดียว

กด **ส่งออกทั้งแฟ้ม** แล้วเลือกชุด

| ชุด | มีอะไร | ใช้เมื่อ |
|---|---|---|
| ชุดส่งลูกค้า | หน้าสรุปงาน + ใบเสนอราคา ใบแจ้งหนี้ ใบกำกับภาษี/ใบเสร็จ ใบลด/เพิ่มหนี้ (พิมพ์ว่าต้นฉบับ) + หลักฐานที่แนบกับเอกสารเหล่านั้น ไม่มีต้นทุนหรือกำไร | ส่งให้ลูกค้าตรวจสอบหรือปิดงาน |
| ชุดเก็บเข้าแฟ้ม (ภายใน) | หน้าสรุปพร้อมค่าใช้จ่ายและกำไร + ทุกเอกสาร (พิมพ์ว่าสำเนา) รวมเอกสารฝั่งซื้อ + หลักฐานค่าใช้จ่าย + ไฟล์ของแฟ้ม | เก็บเป็นหลักฐานของกิจการ หรือส่งให้ผู้ทำบัญชี |

- **ลำดับในไฟล์:** หน้าสรุป → เอกสารแต่ละใบตามวันที่ ตามด้วยหลักฐานของใบนั้น → (ชุดภายใน) หลักฐานค่าใช้จ่ายและไฟล์ของแฟ้ม
- **หน้าสรุป:** มีตารางรายชื่อไฟล์หลักฐานทั้งหมดในชุด ถ้ายาวเกินหนึ่งหน้า ระบบตัดหน้าระหว่างแถวของตาราง
- **เอกสารที่ยกเลิก:** ไม่ถูกรวม
- **ตัวเลือกเพิ่มเติม:** ปิดหน้าสรุป ไม่แนบหลักฐาน หรือไม่แสดงตราสถานะได้

### 9.6 ปิดงาน เปิดใหม่ และลบแฟ้ม

- **ปิดงาน:** เมื่อรับเงินครบและไม่มีค่าใช้จ่ายค้าง แฟ้มจะย้ายไปแท็บ "ปิดแล้ว"
- **เปิดงานอีกครั้ง / ยกเลิก / แก้ชื่องานหรือลูกค้า:** จากเมนู ⋯ หรือปุ่มแก้ไขในหน้าแฟ้มงาน
- **ลบแฟ้ม:** เอกสารและรายการรับ-จ่ายยังอยู่ แค่ไม่อยู่ในแฟ้ม ส่วนไฟล์ที่แนบกับแฟ้มโดยตรงจะถูกลบ
- **รายงานกำไรต่องาน:** ดูได้ที่ **รายงาน > กำไรต่องาน** ส่งออก CSV ได้

## 10. ภาษี

กดลูกศรเพื่อเลือกเดือนภาษี (ค่าเริ่มต้นคือเดือนที่แล้ว ซึ่งมักเป็นเดือนที่ต้องยื่น)

- **ภ.พ.30:** ยอดขาย ภาษีขาย ยอดซื้อ ภาษีซื้อ และภาษีที่ต้องชำระหรือชำระเกิน
  - ดาวน์โหลด **รายงานภาษีขาย** และ **รายงานภาษีซื้อ** เป็น PDF หรือ CSV ได้
  - เตือนภาษีซื้อที่ใช้สิทธิ์ไม่ได้ และใบกำกับที่ใช้สิทธิ์เกิน 6 เดือน
- **หัก ณ ที่จ่ายที่ต้องนำส่ง:** แยก ภ.ง.ด.3 และ ภ.ง.ด.53
  - เตือนเมื่อไม่มีเลขผู้เสียภาษี หรือเลขผิด
  - มีปุ่มออก 50 ทวิ ทีละราย และส่งออกรายการเป็น PDF/CSV
- **ภ.พ.36:** VAT ของค่าบริการจากต่างประเทศ
- **เครดิตภาษีทั้งปี:** ภาษีที่ลูกค้าหักเรา ติ๊ก "ได้รับแล้ว" เมื่อได้ 50 ทวิ ใช้ยอดนี้ตอนยื่นภาษีประจำปี
- **ถ้ายังไม่จด VAT:** แสดงมาตรวัดรายได้เทียบเกณฑ์ 1.8 ล้านบาท
- **กำหนดยื่นที่ใกล้ถึง:** รวมการขยายเวลายื่นออนไลน์และเลื่อนวันหยุดเสาร์-อาทิตย์แล้ว แต่ **ไม่รวมวันหยุดนักขัตฤกษ์**

## 11. รายงาน ผู้ติดต่อ และการตั้งค่า

### รายงาน

- **งบกำไรขาดทุนรายเดือน:** แยกหมวด 12 เดือน ส่งออก PDF/JPEG/CSV
- **ลูกหนี้ / เจ้าหนี้:** อายุหนี้ 5 ช่วง (ยังไม่ครบกำหนด, เกิน 1–30, 31–60, 61–90 และเกิน 90 วัน) พร้อมปุ่มรับชำระ
  - **ยอดค้างเป็นเงินที่จะได้รับหรือต้องจ่ายจริง** คือหักภาษี ณ ที่จ่ายออกแล้ว เช่น ใบแจ้งหนี้ 10,700 บาทที่ลูกค้าหัก 3% จะขึ้นยอดค้าง 10,400 บาท ส่วนอีก 300 บาทได้คืนเป็นเครดิตภาษี (ต่างจากหน้าแฟ้มงานที่แสดงมูลค่างานเต็มก่อนหัก)
  - ใบแจ้งหนี้ที่รับชำระบางส่วนจะเหลือเฉพาะยอดที่ยังค้างในรายงานนี้
  - ถ้ายกเลิกหรือลบใบเสร็จทิ้ง ยอดจะกลับมาเป็นหนี้ค้างให้อัตโนมัติ
  - ถ้าใช้ ⋯ > "ทำเครื่องหมายว่าชำระแล้ว" หนี้จะหายจากรายงานแต่ระบบไม่บันทึกรายรับให้ ต้องบันทึกรายรับเองด้วย
- **กำไรต่องาน:** มูลค่างาน รายได้ ต้นทุน กำไร อัตรากำไร และค้างรับของทุกแฟ้มงาน ส่งออก CSV ได้ (หัวข้อ 9)
- **สินค้าที่ซื้อ:** รวมรายการที่ชื่อเหมือนกันเข้าด้วยกัน บอกจำนวนรวม ช่วงราคาต่อหน่วย (ต่ำสุด–สูงสุด) มูลค่ารวม จำนวนครั้งที่ซื้อ วันล่าสุด และร้านที่ซื้อ เลือกดูฝั่งซื้อหรือฝั่งขายได้ ส่งออก CSV ได้
- **บัญชีเงิน:** ยอดยกมา เงินเข้า เงินออก คงเหลือ ควรเทียบกับสมุดบัญชีธนาคารเป็นประจำ
- **ส่งออกข้อมูล:** CSV รายการทั้งปีหรือทั้งหมด ทะเบียนเอกสาร และไฟล์สำรอง

### ผู้ติดต่อ & สินค้า

- **ผู้ติดต่อ:**
  - ประเภท ลูกค้า / ผู้ขาย / ทั้งสอง

## 12. แชร์ให้คนอื่นใช้

เลือกวิธีตามคนที่จะใช้

| วิธี | เหมาะกับ | AI อ่านใบเสร็จ | ข้อมูลของแต่ละคน |
|---|---|---|---|
| 12.1 ส่งไฟล์ HTML | คนที่ใช้บนคอมพิวเตอร์ | ในเครื่องได้เลย ถ้าจะใช้ AI แต่ละคนใส่ API key ของตัวเอง | อยู่ในเบราว์เซอร์ของเขา |
| 12.2 ทำเป็นเว็บแชร์ลิงก์ | คนใช้มือถือ หรือคนจำนวนมาก | ในเครื่องได้เลย ถ้าจะใช้ AI แต่ละคนใส่ API key ของตัวเอง | อยู่ในเบราว์เซอร์/แอปบนเครื่องของเขา |

ทุกวิธี **ไม่มีใครเห็นข้อมูลบัญชีของคนอื่น** เพราะข้อมูลไม่ได้อยู่ในไฟล์โปรแกรม

### 12.1 ส่งไฟล์ HTML ให้ใช้บนคอมพิวเตอร์

1. ส่ง `samud-banchi.html` ทาง LINE, อีเมล หรือ Google Drive (ไฟล์ประมาณ 6 MB)
2. ผู้รับบันทึกไฟล์ลงเครื่อง เช่น โฟลเดอร์ Documents แล้วดับเบิลคลิกเปิดด้วย Chrome หรือ Edge
3. ข้อมูลบันทึกอัตโนมัติในเบราว์เซอร์นั้น
4. แนะนำให้ผู้รับบุ๊กมาร์กหน้านี้ไว้ และดาวน์โหลดไฟล์สำรองเป็นประจำ

ข้อควรรู้:

- ถ้าย้ายหรือเปลี่ยนชื่อไฟล์ ข้อมูลส่วนใหญ่ยังอยู่ แต่ขึ้นกับเบราว์เซอร์ ปลอดภัยที่สุดคือสำรองก่อนย้าย
- อยากให้ข้อมูลเป็นไฟล์ในโฟลเดอร์ Google Drive: **ตั้งค่า > สร้างไฟล์ข้อมูลใหม่** (Chrome/Edge)

### 12.2 ทำเป็นเว็บ แชร์ลิงก์ ใช้ได้ทั้งมือถือและคอม

เว็บนี้เป็นไฟล์นิ่งล้วน ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ใช้โฮสติ้งฟรีได้ ตัวอย่างนี้ใช้ **GitHub Pages**

**ต้องมี:** บัญชี GitHub (สมัครฟรีที่ github.com) และไฟล์ `samud-banchi-web.zip`

#### ขั้นตอน

1. แตกไฟล์ `samud-banchi-web.zip` ในเครื่อง
2. เข้า github.com แล้วล็อกอิน
3. กดปุ่ม **+** มุมขวาบน > **New repository**
   - Repository name: เช่น `samud-banchi`
   - เลือก **Public** (GitHub Pages แบบฟรีใช้กับ repository สาธารณะ ไฟล์โปรแกรมเปิดเผยได้ เพราะไม่มีข้อมูลบัญชีอยู่ในนั้น)
   - กด **Create repository**
4. ในหน้า repository กดลิงก์ **uploading an existing file** (หรือ **Add file > Upload files**)
5. ลากไฟล์เหล่านี้ไปวาง **ที่ระดับบนสุด** ห้ามใส่ในโฟลเดอร์ย่อย:
   `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
6. กด **Commit changes**
7. ไปที่ **Settings > Pages**
   - Build and deployment > Source: **Deploy from a branch**
   - Branch: **main** และโฟลเดอร์ **/ (root)**
   - กด **Save**
8. รอ 1–3 นาที แล้วรีเฟรชหน้า Pages จะเห็นลิงก์ `https://ชื่อผู้ใช้.github.io/samud-banchi/`
9. เปิดลิงก์ทดสอบ แล้วส่งลิงก์ให้คนอื่น

โฮสติ้งอื่นที่ลากไฟล์วางได้ เช่น Netlify หรือ Cloudflare Pages ก็ใช้ได้เหมือนกัน:

- อัปโหลดไฟล์ทั้งหมดไว้ระดับบนสุดของเว็บ
- เว็บต้องเป็น `https://` ไม่อย่างนั้นการเปิดตอนไม่มีเน็ตจะไม่ทำงาน

#### ติดตั้งเป็นแอปบนมือถือ (แนะนำมาก)

**iPhone / iPad (Safari):**
1. เปิดลิงก์ใน Safari
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก **เพิ่มไปยังหน้าจอโฮม** แล้วกด **เพิ่ม**
4. จากนี้ให้เปิดจากไอคอน "สมุดบัญชี" บนหน้าจอโฮมเสมอ

ทำไมต้องติดตั้ง: Safari อาจลบข้อมูลของเว็บที่ไม่ได้เปิดใช้ช่วงหนึ่ง (โดยทั่วไปประมาณ 7 วัน) แต่เว็บแอปที่เพิ่มไว้บนหน้าจอโฮมไม่อยู่ในนโยบายนี้ ทั้งนี้ยังควรสำรองข้อมูลเป็นประจำอยู่ดี

**Android (Chrome):**
1. เปิดลิงก์ใน Chrome
2. กดเมนู ⋮ มุมขวาบน
3. เลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

หลังเปิดครั้งแรกขณะมีอินเทอร์เน็ต ครั้งต่อไปเปิดได้แม้ไม่มีเน็ต รวมถึงสแกนใบเสร็จแบบในเครื่อง

#### อัปเดตเวอร์ชันใหม่

1. อัปโหลด `index.html` และ `sw.js` ตัวใหม่ทับของเดิมใน repository (Add file > Upload files > Commit changes)
2. ผู้ใช้เปิดแอปครั้งแรก แอประบบจะดาวน์โหลดเวอร์ชันใหม่ไว้เบื้องหลัง พอเปิดครั้งถัดไปจะเป็นเวอร์ชันใหม่
3. ข้อมูลของผู้ใช้ไม่หายเมื่ออัปเดต

### 12.3 เผยแพร่ผ่าน Claude (ผู้ใช้มีบัญชี Claude)

1. ไปที่แชตที่ Claude สร้างไฟล์นี้ให้ แล้วเปิดไฟล์ในหน้าต่าง artifact (การอัปโหลดไฟล์ HTML เข้าแชตใหม่จะไม่กลายเป็น artifact ที่เผยแพร่ได้)
2. กด **Publish** แล้วคัดลอกลิงก์ส่งให้คนอื่น ถ้าไม่เห็นปุ่มนี้ แสดงว่าไฟล์นี้เผยแพร่จากหน้าจอนั้นไม่ได้ ให้ใช้วิธี 12.2 แทน
3. ผู้ใช้ทั่วไปเปิดดูได้ แต่ฟีเจอร์ AI จะให้ล็อกอินด้วยบัญชี Claude ของตัวเอง
4. การใช้ AI นับในโควตาของผู้ใช้แต่ละคน ไม่ใช่ของคนที่แชร์

ข้อควรรู้:

- ถ้ากด Unpublish แล้ว จะเผยแพร่ artifact เดิมซ้ำไม่ได้
- ไฟล์นี้ใหญ่ ถ้าใน Claude โหลดช้าหรือใช้บางฟีเจอร์ไม่ได้ (เช่น การอ่านในเครื่อง การพิมพ์) ให้ใช้วิธี 12.2 แทน
- รายละเอียดล่าสุด: https://support.claude.com/en/articles/9547008-publish-and-share-artifacts

## 13. ใช้ AI อ่านใบเสร็จเมื่อแชร์ให้คนอื่น

หลักคือ **แต่ละคนใช้ AI ในบัญชีของตัวเอง** คนที่แชร์ไฟล์ไม่ต้องจ่ายค่า AI แทนใคร และไม่ต้องให้คีย์ของตัวเองกับใคร

โปรแกรมเลือกวิธีให้อัตโนมัติ:

- **เปิดใน Claude:** ใช้ AI ของ Claude ผ่านบัญชีที่ล็อกอินอยู่
- **เปิดนอก Claude และใส่ API key ของตัวเองไว้:** ใช้คีย์นั้น
- **ไม่มีทั้งสองอย่าง:** อ่านในเครื่องแบบออฟไลน์

### ทาง A: ผ่าน Claude (ไม่ต้องมีคีย์)

- เหมาะกับคนที่มีบัญชี Claude อยู่แล้ว ใช้วิธี 12.3
- การใช้ AI นับในโควตาบัญชี Claude ของผู้ใช้แต่ละคน คนแชร์ไม่เสียค่าใช้จ่าย

### ทาง B: ใส่ API key ของตัวเอง

เหมาะกับคนที่ใช้ไฟล์ HTML หรือเว็บ และยินดีจ่ายค่า AI ตามการใช้งานจริง

**ขั้นที่ 1: สร้าง API key**
1. เข้า Claude Console ที่ https://console.anthropic.com แล้วสมัครหรือล็อกอิน
2. ไปที่เมนู Billing เพิ่มวิธีชำระเงินและเติมเครดิต
3. ไปที่เมนู Limits ตั้งวงเงินใช้จ่ายสูงสุดต่อเดือน (แนะนำ เพื่อกันค่าใช้จ่ายเกิน)
4. ไปที่เมนู API Keys > **Create Key** แล้วคัดลอกคีย์ (ขึ้นต้นด้วย `sk-ant-`) คีย์จะแสดงครั้งเดียว

**ขั้นที่ 2: ใส่คีย์ในโปรแกรม**
1. **ตั้งค่า > AI อ่านใบเสร็จ**
2. เลือกรุ่น: **Claude Haiku 4.5** (ประหยัด เร็ว เพียงพอสำหรับใบเสร็จ) หรือ **Claude Sonnet 5** (แม่นกว่า)
3. วางคีย์ กด **บันทึกคีย์** แล้วกด **ทดสอบการเชื่อมต่อ**
4. ที่หน้าสแกน เลือกวิธีอ่าน **อัตโนมัติ** หรือ **AI (Claude)**

**ค่าใช้จ่ายโดยประมาณต่อใบเสร็จ 1 ใบ** (รูป 1 รูป บวกคำสั่ง ประมาณ 2,000 input tokens และคำตอบประมาณ 300 output tokens)

| รุ่น | ราคาต่อ 1 ล้าน tokens (input/output) | ต่อใบเสร็จโดยประมาณ |
|---|---|---|
| Claude Haiku 4.5 | $1 / $5 | ประมาณ $0.004 (ราว 1,000 ใบต่อ $4) |
| Claude Sonnet 5 | $3 / $15 | ประมาณ $0.01 (ราว 1,000 ใบต่อ $10) |

ราคาอาจเปลี่ยน ตรวจราคาล่าสุดที่ https://docs.claude.com/en/docs/about-claude/pricing

**ความปลอดภัยของคีย์:**
- คีย์เก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่อยู่ในไฟล์ HTML และไม่อยู่ในไฟล์สำรอง จึงส่งไฟล์โปรแกรมหรือไฟล์สำรองให้คนอื่นได้โดยคีย์ไม่ติดไปด้วย
- **ห้ามแชร์คีย์ของตัวเองให้คนอื่น** ใครมีคีย์ใช้เงินในบัญชีคุณได้
- ถ้าคิดว่าคีย์หลุด ให้ลบคีย์ใน Console แล้วสร้างใหม่
- ใช้คีย์เฉพาะบนเครื่องส่วนตัว ไม่ใส่ในเครื่องสาธารณะ
- เมื่อใช้ AI รูปใบเสร็จจะถูกส่งไปประมวลผลที่ Anthropic ถ้าไม่ต้องการ ให้เลือกอ่าน "ในเครื่อง"

### ข้อความสำหรับส่งให้คนที่รับไฟล์

คัดลอกไปส่งพร้อมไฟล์หรือลิงก์ได้เลย:

> **วิธีเปิดใช้ AI อ่านใบเสร็จ (ไม่บังคับ)**
> ถ้าไม่ตั้งค่า โปรแกรมยังสแกนใบเสร็จแบบอ่านในเครื่องได้ แต่ถ้าอยากให้แม่นขึ้น:
> 1. สมัครที่ https://console.anthropic.com เติมเครดิต และตั้งวงเงินใช้จ่ายสูงสุดในเมนู Limits
> 2. เมนู API Keys > Create Key แล้วคัดลอกคีย์
> 3. ในโปรแกรม ไปที่ ตั้งค่า > AI อ่านใบเสร็จ วางคีย์ กดบันทึกคีย์ แล้วกดทดสอบการเชื่อมต่อ
> 4. ใช้รุ่น Haiku 4.5 ค่าใช้จ่ายประมาณ 0.004 ดอลลาร์ต่อใบ คีย์เป็นของคุณคนเดียว อย่าส่งให้คนอื่น

  โปรแกรมนำ VAT เหล่านี้ไปรวมเป็นค่าใช้จ่ายให้
- **ใบกำกับภาษีเต็มรูป:** ต้องมีคำว่า "ใบกำกับภาษี", ข้อมูลผู้ขายและผู้ซื้อ, เลขผู้เสียภาษี, สาขา, เลขที่, วันที่, รายการ และ VAT แยกชัดเจน ถ้าออกเป็นชุดกับใบเสร็จต้องมีข้อความ "เอกสารออกเป็นชุด"
- **ใบลดหนี้ / ใบเพิ่มหนี้:** ต้องอ้างใบกำกับเดิม มีมูลค่าเดิม มูลค่าที่ถูกต้อง ผลต่าง VAT ของผลต่าง และเหตุผล

## 15. ปัญหาที่พบบ่อย

**ข้อมูลหายหลังเปิดใหม่**
- ตรวจมุมซ้ายล่าง ถ้าเป็น "โหมดชั่วคราว" แสดงว่าเบราว์เซอร์ไม่อนุญาตให้เก็บข้อมูล เช่น โหมดไม่ระบุตัวตน (Incognito) หรือ Safari ที่เปิดไฟล์จากเครื่อง
- แก้ไข: ใช้ Chrome/Edge แบบปกติ หรือทำเป็นเว็บตามหัวข้อ 12.2 แล้วกู้คืนจากไฟล์สำรอง
- ถ้าเปิดทั้งใน Claude และในเบราว์เซอร์ ข้อมูลเป็นคนละชุดกัน

**กด PDF/JPEG แล้วไม่มีไฟล์ดาวน์โหลด**
- จะมีหน้าต่าง "ไฟล์พร้อมแล้ว" ขึ้นมา ให้กดปุ่ม **ดาวน์โหลด** ในหน้าต่างนั้น
- บางสภาพแวดล้อม เช่น ใน Claude อาจบล็อกการดาวน์โหลดอัตโนมัติ

**สั่งพิมพ์ไม่ได้**
- ใน Claude อาจถูกบล็อก ให้ใช้ PDF แล้วพิมพ์จากไฟล์ PDF

**สแกนแบบในเครื่องขึ้น "เบราว์เซอร์นี้อ่านในเครื่องไม่ได้"**
- ใช้เบราว์เซอร์รุ่นใหม่: Chrome/Edge/Firefox ล่าสุด หรือ Safari 16.4 ขึ้นไป

**สแกนแล้วไม่มีรายการสินค้า หรือรายการไม่ครบ**
- โหมดในเครื่องจะใส่รายการให้ก็ต่อเมื่อผลรวมของรายการตรงกับยอดบิล ใบเสร็จที่มีส่วนลดแยกบรรทัดหรือพิมพ์ไม่ชัดมักไม่ผ่านเงื่อนไขนี้
- เพิ่มหรือแก้เองได้ที่แถบ "รายการสินค้า" ในการ์ดสแกน หรือหลังบันทึกแล้วเปิดรายการขึ้นมาแก้
- ถ้าต้องการความแม่นสูง ใช้ AI (หัวข้อ 13)

**สแกนแล้วตัวเลขผิด**
- ถ่ายใหม่ให้ตรงและชัด หรือกดหมุนภาพ
- ดูช่อง "ข้อความที่อ่านได้จากภาพ" แล้วแก้ตัวเลขเอง
- หรือตั้งค่า AI (หัวข้อ 13)

**AI ขึ้น "API key ไม่ถูกต้อง"**
- คัดลอกคีย์ใหม่จาก Console โดยไม่มีช่องว่างหัวท้าย แล้วกดทดสอบการเชื่อมต่อ

**AI ขึ้น "เครดิต API หมด"**
- เติมเครดิตใน Console ระหว่างนี้ระบบจะอ่านในเครื่องแทนในโหมดอัตโนมัติ

**แนบไฟล์ไม่ได้**
- PDF ต้องไม่เกิน 15 MB
- รูป HEIC บนคอมพิวเตอร์ต้องแปลงเป็น JPEG ก่อน
- ถ้าพื้นที่เครื่องเต็ม ให้ลบไฟล์เก่าที่ไม่ใช้หรือสำรองแล้วเริ่มใหม่

**รวมไฟล์แนบท้าย PDF ไม่ครบ**
- PDF ที่ล็อกรหัสผ่านหรือเสียหายจะถูกข้าม ระบบแจ้งชื่อไฟล์ ให้ส่งไฟล์นั้นแยก

**เลขที่เอกสารซ้ำ**
- โปรแกรมไม่ให้บันทึกเลขซ้ำในเอกสารประเภทเดียวกัน ให้แก้เลขที่หรือใช้เลขอัตโนมัติ

**ยอดลูกหนี้ไม่ตรงกับที่คิดไว้**
- ยอดในรายงานลูกหนี้หักภาษี ณ ที่จ่ายออกแล้ว ถ้าต้องการดูมูลค่าเต็มให้เปิดที่ตัวใบแจ้งหนี้หรือหน้าแฟ้มงาน
- ใบแจ้งหนี้ที่กด "ทำเครื่องหมายว่าชำระแล้ว" จะออกจากรายงาน แม้ยังไม่ได้บันทึกรายรับ
- รายรับที่บันทึกเองแบบ "ยังไม่ได้รับเงิน" จะนับเป็นลูกหนี้ด้วย ถ้าบันทึกไว้ทั้งใบแจ้งหนี้และรายรับของงานเดียวกัน ยอดจะซ้ำ ให้ลบอย่างใดอย่างหนึ่ง
- เก็บเงินแล้วแต่ไม่ได้ออกใบเสร็จจากใบแจ้งหนี้ ระบบจะยังถือว่าค้างอยู่ ให้เปิดใบแจ้งหนี้แล้วกด "รับชำระ"

**ยอดค้างรับของแฟ้มงานไม่ตรง**
- ตรวจว่าใบเสนอราคาล่าสุดในแฟ้มเป็นยอดที่ตกลงจริง ใบที่ลูกค้าไม่อนุมัติให้ตั้งสถานะ "ไม่อนุมัติ" หรือยกเลิก
- รายรับที่บันทึกเองต้องอยู่ในแฟ้มเดียวกันและสถานะชำระแล้ว
- ถ้ามีการลดหรือเพิ่มราคาหลังออกใบกำกับ ให้ออกใบลด/เพิ่มหนี้ ระบบจะปรับมูลค่างานให้

**อัปเดตเว็บแล้วผู้ใช้ยังเห็นเวอร์ชันเก่า**
- ปิดแอปแล้วเปิดใหม่ 2 ครั้ง (ครั้งแรกดาวน์โหลดเวอร์ชันใหม่ ครั้งที่สองใช้งาน)

**เปิดเว็บตอนไม่มีเน็ตไม่ได้**
- ต้องเคยเปิดขณะมีเน็ตอย่างน้อย 1 ครั้ง
- เว็บต้องเป็น https และอัปโหลด `sw.js` ไว้ระดับเดียวกับ `index.html`

## 16. ข้อจำกัด

- **ไม่ใช่ระบบบัญชีคู่เต็มรูปแบบ:** ไม่มีสมุดรายวันทั่วไป งบดุล หรือทะเบียนทรัพย์สิน/ค่าเสื่อมราคา กิจการนิติบุคคลยังต้องมีผู้ทำบัญชีจัดทำงบการเงิน
- **ไม่ใช่ e-Tax Invoice:** PDF ที่ส่งออกไม่ใช่ e-Tax Invoice/e-Receipt ตามระบบของกรมสรรพากร และไม่ได้ยื่นแบบให้อัตโนมัติ
- **ไม่มีระบบเงินเดือน:** ไม่มีประกันสังคม และไม่ได้คำนวณภาษีเงินได้ประจำปี
- **ข้อมูลไม่ซิงก์ข้ามเครื่อง:** ใช้คนเดียวหลายเครื่องต้องย้ายด้วยไฟล์สำรอง
- **ใช้ร่วมกันพร้อมกันหลายคนไม่ได้**
- **ปฏิทินภาษี:** ไม่รวมวันหยุดนักขัตฤกษ์
- **การอ่านใบเสร็จแบบในเครื่อง:** ไม่รองรับ PDF และแม่นยำน้อยกว่า AI
- **กำไรต่องาน:** นับเฉพาะรายการที่ผูกกับงาน ไม่ได้ปันส่วนค่าใช้จ่ายส่วนกลาง เช่น ค่าเช่า ค่าอินเทอร์เน็ต ให้แต่ละงาน

## 17. สำหรับนักพัฒนา

### โครงสร้างภายในไฟล์ HTML

ทั้งหมดอยู่ใน `samud-banchi.html` ไม่มีการเรียกไฟล์ภายนอก:

| ส่วน | ที่อยู่ในไฟล์ |
|---|---|
| ฟอนต์ Anuphan และ Sarabun (subset ไทย+ละติน, base64 woff2) | `<style>` แรก |
| CSS ของแอป | `<style>` ที่สอง |
| ข้อมูลของตัวอ่านในเครื่อง | `<script type="text/plain" id="ocr-worker">`, `ocr-core` (gzip+base64), `ocr-tha`, `ocr-eng` |
| ไลบรารี | tesseract.js, pdf-lib, html2canvas, qrcode-generator ในแท็ก `<script>` แยกกัน |
| โค้ดแอป (ไม่ได้ย่อ อ่านและแก้ได้) | `<script>` สุดท้าย แบ่งส่วนด้วยคอมเมนต์ `/* ===== ... ===== */` |

ลำดับโมดูลในสคริปต์สุดท้าย:

- `Core`: ฟังก์ชันล้วน ได้แก่ เงินแบบสตางค์ VAT/WHT จำนวนเงินเป็นตัวอักษรไทย ตรวจเลขผู้เสียภาษี QR พร้อมเพย์ วันที่ และตัวเขียน PDF
- `OcrParse` / `OfflineOCR`: แยกข้อมูลจากข้อความใบเสร็จ และตัวอ่านในเครื่อง
- **State & storage:**
  - ค่าคงที่ภาษีและประเภทเอกสาร
  - ตัวเก็บข้อมูล `Store`: artifact / IndexedDB / ไฟล์ / หน่วยความจำ
  - ตรรกะรายงาน
- **UI helpers:** modal, toast, ไอคอน, ตัวตัดคำไทยก่อนแปลงเป็นภาพ
- **Attachments:** ไฟล์แนบ การรวมเข้า PDF
- **Views:** แต่ละหน้าอยู่ใน `VIEWS.<route>` และปุ่มเรียก `ACT.<ชื่อ>` ผ่าน `data-act`
- **Documents:** แม่แบบ A4 ตัวแก้เอกสาร การส่งออก
- **Jobs:** แฟ้มงาน การคิดยอดค้างรับและกำไรของงาน การเรียกเก็บบางส่วน และการส่งออกทั้งแฟ้ม
- **Main:** event delegation การเริ่มต้น การลงทะเบียน service worker

### จุดที่มักอยากแก้

| ต้องการ | แก้ที่ |
|---|---|
| อัตรา VAT | หน้าตั้งค่า หรือ `defaultState().settings.vatRate` |
| อัตราหัก ณ ที่จ่ายในรายการเลือก | `WHT_RATES` |
| หมวดเริ่มต้น | `defaultCategories()` |
| ประเภท/ชื่อเอกสาร | `DOC_TYPES`, `STATUS` |
| คำสั่งที่ส่งให้ AI | `scanPrompt()` |
| รุ่น AI (ใน Claude / นอก Claude) | `callClaude()` และค่าเริ่มต้น `aiModel` |
| คีย์เวิร์ดแยกหมวดตอนอ่านในเครื่อง | `CAT_HINTS` ใน `OcrParse` |
| การแยกรายการสินค้าตอนอ่านในเครื่อง | `parseLines()` ใน `OcrParse` (`NOISE` คือบรรทัดที่ข้าม) |
| วิธีคิดมูลค่างาน ค้างรับ และกำไรของงาน | `jobStats()` |

### รูปแบบข้อมูล

- **ไฟล์สำรองเป็น JSON:** `settings`, `categories`, `accounts`, `txns`, `docs`, `contacts`, `products`, `recurring`, `jobs`, `attachments` (`id → data URL`)
- **รายการสินค้า:** เก็บใน `lines: [{ desc, qty, unit, price, amount }]` ของแต่ละรายการรับ-จ่าย
- **แฟ้มงาน:** `jobs: [{ id, no, name, contactId, cName, status, note, atts }]` เอกสารและรายการผูกกับงานด้วย `jobId` ส่วนยอดเงินของงานคำนวณใหม่จากระเบียนทุกครั้ง ไม่ได้เก็บซ้ำ
- **ไฟล์แนบของแต่ละระเบียน:** เก็บ metadata ใน `atts: [{ id, name, mime, size, label, at }]`
- **ใน Claude:** ข้อมูลหลักอยู่ที่คีย์ `acct-main-v1` ไฟล์แนบอยู่ที่ `acct-att-<id>` ถ้าเกิน 4 MB จะแบ่งเป็น `acct-att-<id>-p0..n`
- **ในเบราว์เซอร์:** IndexedDB ชื่อ `samud-banchi` store `kv` ใช้คีย์ชุดเดียวกัน API key อยู่ที่ `ai-key`
- **ความเข้ากันได้:** ข้อมูลเวอร์ชันเก่าที่มี `attId` เดี่ยว จะถูกแปลงเป็น `atts` ให้อัตโนมัติ

### การเก็บตัวเลขเงิน

- เก็บเป็นจำนวนสตางค์แบบจำนวนเต็ม จึงไม่มีปัญหาเศษทศนิยมเพี้ยนแบบที่เจอในโปรแกรมทั่วไป
- VAT และหักภาษี ณ ที่จ่าย ปัดที่หลักสตางค์ตามที่ใช้จริงบนเอกสาร และตรวจแล้วว่ามูลค่าก่อน VAT บวก VAT เท่ากับยอดรวมเสมอ ทั้งแบบราคารวมและยังไม่รวม VAT
- ยอดค้างรับ ยอดคงเหลือของงาน และการเทียบผลรวมรายการสินค้า ใช้ตัวเลขจริงถึงสตางค์ ไม่มีการกลบส่วนต่างเล็ก ๆ ทิ้ง
- ถ้ายอด VAT บนใบเสร็จต่างจากที่คำนวณเพราะผู้ขายปัดเศษคนละแบบ ให้ใส่ยอด VAT ตามเอกสารในช่อง "ยอด VAT ตามเอกสาร" ระบบจะใช้ตัวเลขนั้นแทน

### การทดสอบที่ทำแล้ว

- **ฟังก์ชันหลัก:**
  - จำนวนเงินเป็นตัวอักษร: เทียบกับไลบรารี `thai-baht-text`
  - QR พร้อมเพย์: เทียบกับไลบรารี `promptpay-qr` ผลตรงทุกกรณี
  - ตัวเขียน PDF: ผ่าน qpdf และ pypdf แบบเข้มงวด
